# ЛР №4. Система видеонаблюдения — вариант А5 «Скрытый режим фотонаблюдения»

Приложение на C++ (Win32 API) для видеонаблюдения с веб-камеры: предпросмотр в
реальном времени, снимки `snapshot_YYYYMMDD_HHMMSS.jpg`, запись видео, журнал
событий, **скрытый (фоновый) режим** со значком в системном трее и глобальной
горячей клавишей `Ctrl+Shift+F12`.

---

## 1. Соответствие заданию (вариант А5)

| Требование методички | Реализация |
|---|---|
| Главное окно со всеми элементами базового монитора | `src/App.cpp`, `src/AppActions.cpp` |
| Область предпросмотра в реальном времени | `App::draw_preview()` — `StretchDIBits` по кадру BGR24 |
| Панель информации: имя, разрешение, FPS, формат пикселей | блок «Информация об устройстве» |
| Кнопки «Подключить», «Снимок», «Начать/Остановить запись» | `IDC_CONNECT`, `IDC_SNAPSHOT`, `IDC_RECORD_START`, `IDC_RECORD_STOP` |
| Поле выбора каталога сохранения | `IDC_DIR_EDIT` + «Обзор…» (`SHBrowseForFolderW`) |
| Индикатор состояния камеры с цветовой индикацией | цветной кружок в заголовке (серый/жёлтый/зелёный/красный) |
| Журнал событий с временными метками | ownerdraw-список + `Logger` (дублирование в `camera_log.txt`) |
| Кнопка «Сохранить отчёт» | `IDC_REPORT` → `report_YYYYMMDD_HHMMSS.txt` |
| **Кнопка «Свернуть в трей»** (`Shell_NotifyIcon`) | `App::hide_to_tray()`, значок + контекстное меню |
| **Глобальная горячая клавиша** (`RegisterHotKey`, `Ctrl+Shift+F12`) | `HOTKEY_SNAPSHOT` в `on_create()` |
| **Снимок в фоне без открытия окна**, имя `snapshot_YYYYMMDD_HHMMSS.jpg` | `App::take_snapshot(true)` из `WM_HOTKEY` |
| **Всплывающее уведомление (balloon tip)** | `App::show_balloon()` (`NIF_INFO`) |
| **Восстановление окна по двойному клику на значке** | `WM_APP_TRAY` + `WM_LBUTTONDBLCLK` |
| **Журналирование фоновых операций** | уровень `BACKGROUND` в журнале (события скрытого режима) |
| Автообновление списка камер | `DeviceMonitor` + `WM_DEVICECHANGE` + `RegisterDeviceNotification` |

Дополнительно: автопереподключение камеры, тёмная/светлая тема, сохранение
настроек в реестре (`HKCU\Software\CameraLab4`), два бэкенда захвата на выбор.

## 2. Требования

* Windows 10/11 x64;
* Visual Studio 2019/2022 с рабочей нагрузкой «Разработка классических
  приложений на C++» (MSVC + Windows SDK);
* CMake 3.16+;
* OpenCV 4.x для Windows (`opencv-4.x.x-windows.exe`), переменная окружения
  `OpenCV_DIR` = `<opencv>\build`.

> OpenCV используется для захвата (`cv::VideoCapture`) и кодирования
> (`cv::imwrite`, `cv::VideoWriter`) — это согласовано с преподавателем.
> Весь интерфейс, скрытый режим, трей, горячие клавиши, журнал, отчёты,
> мониторинг устройств и работа с файлами написаны на чистом Win32 API.
> Дополнительно в проекте есть **второй, «низкоуровневый» бэкенд на Media
> Foundation** (`IMFSourceReader` + ручная конвертация RGB32/YUY2/NV12 → BGR),
> который включается в интерфейсе в списке «Бэкенд захвата». Снимок всегда
> можно сохранить в BMP без OpenCV (резервный путь в `MediaSaver.cpp`).

## 3. Сборка

```bat
set OpenCV_DIR=C:\opencv\build
build.bat
```

или вручную:

```bat
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 -DOpenCV_DIR=%OpenCV_DIR%
cmake --build build --config Release
```

Результат: `build\bin\Release\CameraLab4.exe` (DLL OpenCV копируются рядом с
`.exe` автоматически, если CMake их нашёл).

Сборка в Visual Studio: «Открыть локальную папку» → CMake подхватит
`CMakeLists.txt`, либо `cmake -S . -B build` и открыть `build\CameraLab4.sln`.

Сборка через MinGW возможна (`build_mingw.bat`), но требует OpenCV, собранного
тем же MinGW.

## 4. Работа с приложением

1. Запустить `CameraLab4.exe`. Windows при первом обращении к камере спросит
   разрешение: **Параметры → Конфиденциальность → Камера**.
2. Выбрать камеру, разрешение, частоту кадров и бэкенд → **«Подключить камеру»**.
3. **«Снимок»** — сохраняет JPEG в выбранный каталог (имя
   `snapshot_YYYYMMDD_HHMMSS.jpg`), **«Начать запись»** — AVI/MJPEG
   (`video_YYYYMMDD_HHMMSS.avi`).
4. **«Свернуть в трей»** — окно скрывается, камера продолжает работать.
   Нажатие `Ctrl+Shift+F12` из любого приложения создаёт снимок и показывает
   уведомление. Двойной щелчок по значку возвращает окно.
5. **«Сохранить отчёт»** — выгрузка журнала в `report_YYYYMMDD_HHMMSS.txt`;
   журнал также непрерывно пишется в `camera_log.txt` рядом со снимками.

### Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+Shift+F12` | Снимок (работает глобально, в том числе при скрытом окне) |
| Двойной клик по значку в трее | Показать окно |
| Правый клик по значку | Меню: показать окно / снимок / запись / выход |

### Файлы результатов

```
<каталог сохранения>\
    snapshot_20261028_183012.jpg   снимки
    video_20261028_183500.avi      видеозаписи (MJPEG)
    camera_log.txt                 журнал (append, UTF-8)
    report_20261028_190000.txt     отчёт по кнопке «Сохранить отчёт»
```

Каталог по умолчанию: `%USERPROFILE%\Pictures\CameraLab4`.

## 6. Как устроен скрытый режим

```
       Ctrl+Shift+F12 (RegisterHotKey)
                   │
                   ▼
   WM_HOTKEY ─► App::take_snapshot(true)
                   │
                   ├─► CaptureController::get_latest()  ← поток захвата (30 к/с)
                   ├─► MediaSaver::save_snapshot()      → JPEG в каталог
                   ├─► Logger::background()             → журнал + camera_log.txt
                   └─► Shell_NotifyIcon(NIF_INFO)       → balloon tip
```

Окно при этом скрыто (`ShowWindow(SW_HIDE)`), поток захвата продолжает
работать, поэтому снимок делается «мгновенно» без повторного открытия камеры.
Если камера не была подключена, при сворачивании в трей она подключается
автоматически.

## 7. Возможные проблемы

| Симптом | Причина / решение |
|---|---|
| «Камера не обнаружена» | Камера занята другим приложением или запрещён доступ в «Параметры → Конфиденциальность → Камера» |
| Список камер пуст, а камера есть | Обновите список кнопкой «Обновить», смените бэкенд на Media Foundation |
| Не регистрируется `Ctrl+Shift+F12` | Комбинацию заняло другое приложение (в журнале будет предупреждение) — закройте его или измените клавишу в `App.cpp` (`RegisterHotKey`) |
| Видео не пишется | Проверьте, что каталог доступен на запись; для AVI/MJPEG размеры кадра должны быть чётными (приводятся автоматически) |
| Кириллица в пути | Поддерживается: OpenCV вызывается с UTF-8-путём, при отказе — с ANSI-путём |
